# Shreyansh Mittal - Portfolio

A modern, high-performance, and interactive portfolio website designed to showcase my skills, projects, and experience as a Full Stack & AI Developer.

## ✨ Features

- **Interactive Cyber-Drone Hero:** A highly customized, animated SVG cyber-drone that responds to user input with holographic rings and scanline effects.
- **Physics-Based Skill Grid:** A spring-physics grid showcasing 21 technical skills, reacting to mouse proximity with a dynamic repelling effect.
- **Hand-Gesture & Motion Tracking:** An integrated, vanilla JavaScript camera control system allowing users to steer the drone using their hand or motion, completely in the browser without external libraries.
- **Dynamic Particle System:** A custom canvas-based "blossom" particle engine that responds to cursor velocity and screen boundaries.
- **Fully Responsive & Deep-Dark Theme:** Designed with a premium deep-navy/pink-accented palette, styled beautifully for both desktop and mobile screens.

## 🚀 Technologies Used

This project was built from scratch without bulky frameworks to ensure maximum performance and minimum load times:
- **HTML5 & Semantic Structure**
- **Vanilla CSS3** (Custom Animations, Flexbox, CSS Variables, Glassmorphism)
- **Vanilla JavaScript** (Physics Math, Offscreen Canvas processing, `requestAnimationFrame`, MediaDevices API)
- **Devicon** (For high-quality technology icons)
- **Google Fonts** (Playfair Display & Inter)

## 📸 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ShreyanshMittal1921/portfolio_main.git
   ```
2. **Open the site:**
   Simply double-click the `index.html` file or open it in any modern web browser (Chrome, Edge, Firefox, Safari).
   ```bash
   # Or using a quick local server (Optional)
   npx serve .
   ```
3. **Try the Camera Feature:**
   Click the **"📷"** button in the navigation bar to enable your webcam. Once permitted, wave your hand in front of the camera to control the drone!
